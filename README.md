# aiera-media

Public image and video slides for the **AIERA** Instagram page ([@aiera.news](https://www.instagram.com/aiera.news/)).

Files are laid out as `<date>/<post>/slide-NN.png` (or `.mp4` for official-video slides) and are fetched by Metricool when a post is scheduled. Every slide carries its source ("Fonte: …") and credits; the editorial pipeline lives elsewhere.
